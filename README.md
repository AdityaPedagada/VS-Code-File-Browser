# File Browser

A powerful VS Code extension that provides a full-featured file browser for your system, right inside the VS Code editor.

## Overview

File Browser allows you to browse, search, and manage files on your entire system directly from VS Code. It mimics the functionality of Windows Explorer while integrating seamlessly with VS Code.

## Features

### Navigation
- **Windows Explorer-Style Address Bar**: Click any folder in the path to navigate directly
- **Quick Access**: Click path separators (/) to see subfolders and jump to any level
- **Edit Mode**: Click the edit icon or press Enter in the address bar to type custom paths
- **Drive Selection**: On Windows, navigate to root (/) to see all available drives

### File Operations
- **Create**: New files and folders
- **Open**: Open files in VS Code or in new windows
- **Rename**: Rename files and folders
- **Delete**: Delete files and folders with confirmation
- **Cut/Copy/Paste**: Full clipboard support
- **Open in Explorer**: Launch file location in system file explorer

### Search
- **Local Search**: Filter files in current directory
- **Global Search**: Recursive search through all subfolders
- **Progress Tracking**: Real-time search progress
- **Cancel Support**: Cancel long-running searches

### View & Sorting
- **Grid/List View**: Toggle between grid and list layouts
- **Multiple Sort Options**: Sort by name, date, type, or size
- **Sort Direction**: Ascending/descending toggle

### Properties
- **File Details**: View file size, type, and modification date
- **Folder Size**: Calculate and display folder sizes
- **Progress Display**: Visual progress for long operations

## Installation

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "File Browser"
4. Click Install

## Usage

1. Open the File Browser panel from the VS Code sidebar
2. Browse files by clicking on folders
3. Use the address bar for quick navigation between folders
4. Right-click files for context menu operations
5. Use the search icon for recursive file search

## Keyboard Shortcuts

- **Enter**: Navigate to typed path (in address bar)
- **Escape**: Cancel editing / Close context menus

## Platform Support

- **Windows**: Full support with drive navigation
- **macOS/Linux**: Standard file system navigation
